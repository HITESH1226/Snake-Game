# Snake-Game
A classic Snake Game developed in C using fundamental programming concepts such as functions, arrays, loops, conditional statements, random food generation, score tracking, collision detection, and dynamic snake movement. This project was built to strengthen problem-solving skills and understand game development using core C programming.

# 🐍 Snake Game in C

A classic console-based Snake Game developed in **C Programming**. This project demonstrates fundamental programming concepts such as functions, arrays, loops, conditionals, random number generation, score tracking, and collision detection.

## 📌 Features

- 🎮 Console-based Snake Game
- 🐍 Dynamic snake movement
- 🍎 Random food generation
- 📈 Score tracking
- 💥 Wall collision detection
- ⌨️ Keyboard controls (W, A, S, D)
- 🔄 Real-time game updates
- 🧠 Built using core C programming concepts

## 🛠️ Technologies Used

- C Programming Language
- Dev-C++
- Standard C Libraries
  - stdio.h
  - stdlib.h
  - conio.h
  - windows.h
  - time.h
